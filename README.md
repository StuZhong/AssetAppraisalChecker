# AssetAppraisalChecker

**资产评估报告 Word 文档一致性校检工具**

**A Word document consistency checker for asset appraisal reports, built with C# and Open XML SDK.**

---

## 项目简介 / Overview

AssetAppraisalChecker 是一个面向资产评估报告的 Windows 桌面校检工具。

项目主要用于检查同一份 `.docx` 资产评估报告中，在不同位置重复出现的关键业务信息是否保持一致，从而辅助发现人工编制、复制、修改过程中可能产生的前后矛盾问题。

项目当前公开版本为 **V1**。

V1 的核心目标并不是普通的文字校对或全文字符串搜索，而是：

> **识别资产评估报告中的业务字段，对相关数据进行提取、标准化、分类和一致性比较。**

---

## V1 主要能力 / Features

V1 主要针对 **单个 Word 资产评估报告内部的一致性** 进行校检。

目前的校检体系主要涉及：

- 项目名称等关键文字信息的一致性检查
- 报告编号等标识信息的一致性检查
- 评估基准日、报告日期等日期信息的识别与标准化
- 评估值等金额信息的识别、换算与比较
- 中文金额与阿拉伯数字金额的处理
- 正文与表格中的相关业务信息提取
- 对同一业务含义在不同位置出现的数据进行一致性判断
- 对异常和冲突生成诊断结果
- 对原始 `.docx` 报告进行只读处理，不修改原文件

> 具体支持范围和边界以 V1 源代码、测试规则及自动化测试为准。
